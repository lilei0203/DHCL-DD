# Implementation and provenance notes

## What was available

The source was the supplied revised LaTeX manuscript, not an original executable model or training log. This is an independent reconstruction. Newly downloaded public data and newly generated splits are recorded explicitly; no image-estimated values are treated as raw observations.

## Equation mapping

| Manuscript operation | Implementation |
|---|---|
| `H = blockdiag(R, R.T)` | `graph.build_graph`; vertex order users/items; edge order items/users |
| Group mean, nonlinear member compatibility, within-edge softmax | `model.AttentionLayer.forward` |
| Exact overlapping candidates, top-q Jaccard plus self | `graph.exact_neighbors`; blocked sparse multiplication, no approximate neighbor truncation before Jaccard |
| Q/K/O edge attention and softmax over retained neighbors | `model.AttentionLayer.forward` |
| Renormalized alpha over incident edges, half residual update | `model.AttentionLayer.forward`; isolated vertices carried unchanged |
| Average readout over initial embeddings and all layers | `model.DHCLDD.encode` |
| Detached original-view cosine snapshot | `graph.filter_interactions` |
| `min(degree, max(k_min, ceil(gamma*degree)))` and item restoration | `graph.filter_interactions`; item ties by item ID, restoration ties by user ID |
| Distinct user and item sets, symmetric cross-view InfoNCE | `model.contrastive_loss`; positive AND sampled negative items included |
| Mean BPR plus normalized embedding/parameter regularization | `train.train_step` and `model.DHCLDD.regularization` |
| Original-view full ranking with split-specific masking | `evaluate.evaluate` |

Attention parameters are shared between channels and between original/filtered views, but not between layers. Each BPR optimization step recomputes current differentiable representations. Gradient checkpointing recomputes activation tensors during backward; it does not cache detached embeddings across optimizer steps. Filtering occurs once per post-warm-up epoch, before updates, and the filtered graph is held fixed within that epoch. Ranking always uses the original graph.

## Choices not fully specified by the manuscript

- Original split seed and training seeds were unavailable. Reconstruction seed is 2026.
- Integer split rounding is defined in `data.preprocess`; duplicate ratings are positive if at least one retained row meets the threshold.
- Encoder matrix/vector initialization uses Xavier uniform; attention bias is zero. The manuscript specified Xavier ID embeddings but not every attention parameter's initialization.
- Adam uses PyTorch defaults (`betas=(0.9,0.999)`, `eps=1e-8`) with no optimizer weight decay; the manuscript's normalized explicit regularizer is used instead.
- Evaluation ties use ascending item ID. Neighbor/retention ties use the manuscript's fixed IDs.
- Empty candidate sets have self edges; isolated vertex outputs retain their input. Evaluation excludes items without training support.
- Uniform training negatives exclude training positives only, as stated in the manuscript. Held-out labels do not influence training negative sampling.
- No projection head, extra dropout, AMP, gradient clipping, approximate graph pruning, or sampled-negative evaluation was added.

## Dataset discrepancies requiring manuscript reconciliation

The downloaded Douban file contains 13,024 users, 22,347 items and 792,062 ratings, matching the manuscript table BEFORE its stated filtering. After rating >=4 and iterative 5-core, the actual result is 10,424 users, 20,056 items and 586,056 interactions. The manuscript labels its table as after preprocessing, which is inconsistent with these rules. The code follows the stated rules and records the resulting data, rather than changing the threshold to force a match.

The LightGCN Amazon-Book release reports 52,643 users; the manuscript lists 52,463. Actual postprocessing statistics for all three releases are in `data/*/processed/statistics.json`. These differences mean the new run cannot be directly compared to manuscript baseline numbers.

## Scope of the local run

The executable paper configuration remains available (64 dimensions, 2 layers, BPR batch 1024, warm-up 10, maximum 500 epochs, validation every 5, patience 20). The local configuration uses 12 complete epochs and batch 8192 to exercise warm-up, dynamic filtering, joint optimization, validation model selection and test evaluation on the full processed Douban dataset within available resources. This run is a functional reconstruction experiment, not evidence of convergence, statistical superiority, five-seed robustness, or a match to the published table.

The manuscript's figures, ablations, noise experiments and five-seed comparisons are not regenerated by this single run. Test results in the delivered log are measured; no target Recall/NDCG is hardcoded in the model or evaluator.

## Archiving

The folder is local and has no DOI. Source commit IDs and SHA-256 hashes provide an acquisition trail. Prior to a public archive, verify rights for the third-party data and reconcile the manuscript with actual experiments. A DOI must be minted by an archive service after depositing the real release; no DOI is fabricated here.
